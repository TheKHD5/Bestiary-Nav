Adds **Cancel auto travel when manually moving** under `/bnav` settings.

- Off by default; saved automatically when changed.
- When enabled, movement keys (including remapped bindings), the controller movement stick, or holding both mouse buttons cancel the current trip.
- Cancels mesh waits and pathfinding as well as walking. Late pathfinding results cannot restart travel.
- Auto Navigate remains enabled for your next Bestiary selection.
- A teleport already completed cannot be undone; cancellation prevents follow-up walking.

Update Bestiary Nav through `/xlplugins` using the existing custom repository. Lifestream and vnavmesh remain separate dependencies for automatic travel.

Validation: Release build with zero warnings/errors; 467 data/navigation/travel checks and 25 native row checks passed. In-game input behavior remains to be verified.
