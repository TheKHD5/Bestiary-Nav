# Bestiary Nav 0.6.3

- Optional capture runs in the Capture settings tab, using Rotation Solver Reborn's BST rotation.
- Select an uncaptured entry to travel, target the closest eligible matching beast in that spawn area, apply Capture, and fight.
- Pause at least three seconds after each defeat and recheck capture records before retrying. Stop when captured.
- Stop the run through the anchored toolbar, Capture settings, or `/bnav stop`.
- A **Go to next target** button beneath the Bestiary toolbar toggles starts navigation to the next eligible uncaptured collection recommendation. It uses the capture run when enabled.
- When no eligible beast is nearby, walk survey points inside the configured spawn circle and scan along the way. Skip points without a reachable route inside that circle. Widen **Search radius** for larger spawn areas, up to 200 yalms; select the entry again to apply it. Each sweep is limited to ten minutes, within the overall thirty-minute run limit.
- Keep the destination through teleport loading, temporary player/UI absence, and Rotation Solver's rotation refresh. Wait for Lifestream and the destination mesh before continuing toward the selected spawn area.
- **Capture all available** in the Capture settings and Bestiary toolbar works through uncaptured overworld entries at your current BST level. Uses the existing travel, spawn search, Capture, and Rotation Solver flow. Stops when no eligible overworld entries remain; duties and quests are excluded.
- Failed batch entries retry with a 15–120 second backoff, attempting other eligible beasts and cycling through documented locations in between. Each attempt waits at least three seconds for capture records before progressing. Combat, death, unavailable dependencies, and job changes wait for recovery. You must handle revival or job changes yourself.
- Batch mode is session-only. Turning it off, `/bnav stop`, disabling capture runs or Location pop-up, selecting another destination, manual movement when enabled, logout, and reload cancel all retries. Enabling the batch turns on capture runs and Location pop-up. It never changes Rotation Solver's saved settings or takes over an already active rotation mode.

Requires Rotation Solver Reborn 7.5.6.8+ with its BST rotation selected, plus vnavmesh and Lifestream for travel. Start with Rotation Solver off and its Teaching Mode and Auto On settings disabled. Bestiary Nav uses its external-control mode to keep hostile actions on the main target, pauses it between attempts, and returns it to Off when finished. Changing its operating mode yourself stops the run without overwriting your new mode. Saved Rotation Solver settings are unchanged. Standalone Auto Capture and its HP threshold remain separate; capture runs mark before enabling damage combos.

Dungeon entry and navigation through the dungeon remain manual. Select the Bestiary entry again when near its target inside the duty. Quest-only entries do not start capture runs. Runs stop on target changes, missing dependencies, death, job changes, or leaving the area. Manual movement cancels the run when that setting is enabled.

## Validation

Capture retries now wait three seconds. Target changes or clears end the current attempt without disabling Capture all; it rechecks records and retries when safe. Living, targetable respawns are eligible even if their object ID was previously defeated. Manual-movement cancellation remains explicit, and its reason stays visible in Capture settings.

The initial Rotation Solver capture loop was confirmed working in game. Local checks also cover bounded spawn-area surveys, unreachable routes, a Coeurl #33 cross-zone regression with delayed player/UI loading and Lifestream completion, and batch eligibility, delayed capture results, completion, cancellation, dependency recovery, and repeated failures. The initial capture loop was tested in game. The latest target-loss and respawn fixes passed local regression checks and were installed for testing; they have not yet been confirmed in a complete in-game batch run.
