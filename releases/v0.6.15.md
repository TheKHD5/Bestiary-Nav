# Bestiary Nav 0.6.15

- Added **Privacy → Share optional usage statistics**, disabled by default for new and existing users.
- Reports only a random installation ID and plugin version about every five minutes while enabled. Reset the ID or switch reporting off anytime.
- Added a private maintainer dashboard for participating installations, recent activity, versions and GitHub downloads.

Reporting uses no character/account details or gameplay data and does not affect plugin features. Read the [privacy notice](https://github.com/TheKHD5/Bestiary-Nav/blob/v0.6.15/PRIVACY.md).

Game compatibility is unchanged from 0.6.14. Its remaining live checks are still disclosed in diagnostics.
