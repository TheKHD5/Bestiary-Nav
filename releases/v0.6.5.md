# Bestiary Nav 0.6.5

- Add a Farming (Experimental) tab in `/bnav config`. Choose a minimum and maximum offset from +1 to +5 levels above BST. Select a documented, reachable overworld spawn area, travel there, patrol, and fight with Rotation Solver. Captured beasts are valid farming targets; Auto Capture is suspended during farming.
- Keep the chosen target band while leveling and move on once BST reaches its maximum. An optional target level stops farming immediately when reached. Changing the offset range stops the current run so it can be restarted with the new range.
- Optionally consume Gysahl Greens to summon the companion chocobo, and select a normal/HQ food from the four inventory bags. Preserve existing Well Fed; refresh only after expiration while stationary, dismounted, and out of combat. Missing supplies do not stop farming.
- Identify inventory food by the stable Meal category ID rather than its display text, and show an explanation when no usable food is in the bags.
- Optionally detour to active combat FATEs in the current territory within the configured level range. No NPC conversations, escorts, or item hand-ins. Ignore Notorious Monsters excludes hunt entries and boss-ranked enemies from planned pulls; incidental attackers may still be fought in self-defense.
- Keep farming enabled after incapacitation. Auto respawn uses only the revive agent's own enabled confirmation button, waits through loading and HP recovery, then resumes area selection. With auto respawn disabled, wait for manual revival. Failed areas are temporarily excluded.
- Farming and capture automation are mutually exclusive. `/bnav stop`, logout, changing jobs, selecting another destination, and manual movement when configured cancel farming. Rotation Solver mode ownership is preserved; automation does not override a manually changed mode.

The initial catalog contains sourced ARR spawn areas with target levels up to 49, supplemented by live combat FATEs. It is not a complete leveling route for every offset or every level. Missing suitable areas or locked aetherytes produce a status message instead of inventing a route. Source URLs are included in `BestiaryNav/farming-areas.json`; additional entries resolve territory/map/NPC IDs from the installed game sheets.

## Validation

Local checks cover offset ranges, level-up transitions, target-level stops, FATE and notorious-monster filtering, sourced catalog fields, and safe revive-button reading on native fixtures. Compilation and existing capture/travel checks are required. Actual combat, food and chocobo use, FATE completion, respawn dialog handling, and return travel require in-game testing; they have not yet been verified live.
