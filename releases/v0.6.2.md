# Bestiary Nav 0.6.2

- Add an opt-in **Auto Capture main target** setting under **Capture**. Requires BST, combat, a living/targetable catalog beast, an uncaptured Bestiary entry, and a target level no higher than the player.
- Use Capture only on the current main target when the game reports it usable. Respect casting, action queues, animation lock, cooldown, and target restrictions. Never switch targets or start combat.
- Wait while any loaded battle actor has Interest Captured applied by the player. Remember unexpired marks on actors that leave the object table; use the player's Capturing Interest buff conservatively when enabling without a known marked actor.
- Retry after the mark disappears if no other own mark remains and the main target is still eligible. Apply a server-acknowledgement grace period and bounded retry backoff.
- Add a configurable HP threshold, defaulting to 100% (cast as soon as eligible). Active own marks are never refreshed merely because HP falls.
- Keep status in settings and Copy diagnostics, with successful attempts in the plugin log rather than chat spam.
- Shorten Discord release announcements to brief installer-style feature bullets, a GitHub details link, and the update command. Exclude validation sections; ordinary pushes show at most three commit subjects.
