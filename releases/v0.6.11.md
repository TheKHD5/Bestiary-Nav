# Bestiary Nav 0.6.11

- Select multiple monster groups and zones in Levelling settings. The checklist stays open while selecting; each group shows its levels and location. Existing single-group settings migrate automatically. Outgrown saved groups remain removable. Clearing all selections returns to Automatic.
- Try another eligible selected group after an empty patrol, or wait 60 seconds and patrol again. Failed routes retry after two minutes. Neither failure permanently excludes an eligible group or turns Levelling off. A BST 38 character configured for +3–10 can continue searching for level 41–42 Golden Fleece.
- Start the next patrol from the current position when already inside the correct spawn circle, instead of routing back to its center. Ground-path checks still apply to each patrol point.
- Selected species in the current territory can qualify within the active patrol circle; level, FATE, and Notorious Monster filters still apply. Defense continues to take priority. Other selected eligible destinations are available when the current group is outgrown or temporarily unavailable.
- Diagnostics list all selected groups and the last search result. Target-level completion, no eligible accessible destinations, manual cancellation, and existing safety stops remain in effect.
