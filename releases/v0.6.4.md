# Bestiary Nav 0.6.4

- Capture all stays on the selected overworld entry through failed attempts. It advances when capture records confirm success, or the entry is no longer eligible at the current level. An unsuccessful kill no longer causes travel to another beast during the retry delay.
- When retrying on foot inside the selected spawn circle, resume searching locally instead of mounting and returning to the center. Failed attempts retain the existing 15–120 second backoff; capture results still have a three-second wait.
- Continue approaching a moving target while Capture is pending, as well as during initial approach and combat.
- Show Auto Capture's current waiting reason while awaiting Interest Captured. Diagnostics retain the last active status after cancellation.
- Watch for eight seconds without damage while in range of the living, selected, marked target. Refresh the owned Rotation Solver mode and attempt one game-validated Smash Axe opener on that same beast to establish combat. Recovery remains throttled, pauses while casting/approaching or missing the mark, and never overwrites a mode changed by another controller. Rotation Solver continues handling normal combos. Diagnostics record recovery attempts and game rejection codes.
- If the capture-area center has no mapped ground or no complete route, try survey points inside that same circle. Each candidate must have valid ground and a complete path before movement starts; underground floor restrictions remain enforced. Exhausting the bounded set reports a failed attempt for batch retry.
- Approach distant loaded beasts before setting the main target. If that target clears, reacquire it in range; if the actor disappears while approaching, resume the patrol immediately. Capture starts only after the target handoff is confirmed.
- Repeat reachable patrol sweeps inside the spawn circle while scanning for the selected beast. Pause three seconds between sweeps, skip unmapped points, and stop for explicit cancellation or the existing overall run timeout. Local patrol points no longer wait for an unnecessary teleport settle delay.

- When unrelated enemies attack during capture travel or patrol, pause the saved route, dismount, and use Rotation Solver against enemies actively targeting the player. Resume the destination or search after combat clears. Capture all can also defend during its retry wait. Matching, eligible attackers receive Capture first when no other beast holds your mark. Ordinary attackers can be fought without Capture; the recovery opener is restricted to the owned attacker. Manual cancellation and solver ownership checks still apply.

Manual movement still cancels the batch when **Cancel travel on manual movement** is enabled. Turn that setting off if you want to move manually without canceling the batch; Stop and `/bnav stop` remain available.
