# Bestiary Nav 0.6.14

Updates compatibility for Dalamud 15.0.3.5 and FFXIV 2026.09.15.0000.0000.

- Rebuilds against the updated native bindings, including the new Utf8String constructor signature.
- Revalidates capture-target IDs against the updated game data.
- Keeps exact game/version checks and reports the current validation status in diagnostics.

Loading and capture-record reads were confirmed in-game. Entry navigation, visible labels,
travel and combat have not yet been reconfirmed on this patch. See the
[compatibility notes](https://github.com/TheKHD5/Bestiary-Nav/blob/v0.6.14/BestiaryNav/COMPATIBILITY-2026-09-18.md).
