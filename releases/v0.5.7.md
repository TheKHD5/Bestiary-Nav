Fixes installer image delivery after GitHub's raw image endpoint returned HTTP 503 during icon loading.

- Serve the same icon and screenshots through jsDelivr's GitHub CDN.
- Pin unchanged images to their existing published asset tag.
- Preserve the author as TheKHD5.

If the current installer session cached a missing icon, use `/xldev` → Plugins → Clear cached images/icons to retry the download. This clears the installer's image cache without changing plugin settings.
