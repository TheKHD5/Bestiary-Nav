# Bestiary Nav 0.6.1

- Auto Navigate targets the same rounded world coordinates as the selected spawn-area circle. It does not read a map flag.
- Resolve the center's altitude without excluding polygons marked unreachable by vnavmesh's optional mesh classification. Require a complete path before moving.
- Prefer the center itself; if obstructed, allow a nearby mesh point within 20 yalms and inside the circle radius.
- Summon Mount Roulette once when available, then use flying pathfinding and movement when the game permits takeoff. Existing mounts are preserved.
- Use ground travel when mounting/flight is unavailable, or when flying pathfinding fails while still on land. Never switch an airborne character to ground movement after a failed flying route.
- Preserve stop, combat, manual-movement cancellation, dependency ownership, and timeout checks during mounting and flight.
- Route No. 40 (Ghost/Bogy) into its underground section using a verified height band and a ground path through the connected entrance. Reject the surface above it and require landing before starting an underground route while airborne.
- Add a Chat settings tab with a master Print in chat toggle, seven message categories, a default channel, and per-category channel overrides. Routine location and travel messages are off by default. All output stays in the local chat log; muted messages remain available in plugin logs and the latest-message display.
- Add Modern, Classic, and Compact UI styles with seven palettes: Midnight, Forest, Amethyst, Ruby, Ocean, Amber, and Parchment. Mix any style and palette, adjust window opacity, or use your existing Dalamud theme. Settings, collection, and the anchored toolbar share the appearance; capture-label colors remain independent.
- Allow settings and collection windows to resize with the native bottom-right corner grip and remember their sizes. Remove fixed maximum sizes, provide scrollbars for smaller windows, and stack palette/chat controls at narrower widths.
- Give title-bar options, collapse, and close buttons separate hit targets across all three themes, UI scales, and touch padding settings, without widening controls inside the windows.
- Move the native collapse triangle to the left of settings and collection titles, keeping it away from the close button on the right. Restore the original title-bar layout after drawing Bestiary Nav.

Local validation: Release build with zero warnings/errors; 772 functional checks (including title-bar hit-target separation, all 21 saved theme combinations, palette contrast, underground routing, and chat filtering) and 36 native fixture checks passed. The original No. 31 floor failure was reproduced against the installed vnavmesh and cached Lower La Noscea mesh; the revised projection lands about 0.24 yalms from the circle center. No. 40's underground destination has a complete 40-polygon ground corridor from the surface in the cached Middle La Noscea mesh. New native call signatures each match once in the supported executable; Mount Roulette's sheet ID is confirmed.

Validation limits: automated checks and cached-mesh inspection do not replace in-game testing. Live flight, underground arrival, and the final title-bar layout have not yet received explicit confirmation.
