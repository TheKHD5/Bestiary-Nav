First installable release of **Bestiary Nav**, available through its custom Dalamud repository.

- Click Master's Bestiary entries to open map flags, Duty Finder, or quest guidance.
- Show nearby uncaptured beasts on models and the enemy list, with green/red level colors.
- Count unique nearby targets and clear markers when a beast is captured.
- Toggle **Auto Navigate** above the Bestiary's top-left corner for automatic teleporting and walking.
- Use `/bnav` for settings, `/bnav go <number/name>` for a trip, and `/bnav stop` to stop travel.

**Install:** add this URL under Dalamud Settings → Experimental → Custom Plugin Repositories, then find Bestiary Nav in `/xlplugins`:

```text
https://raw.githubusercontent.com/TheKHD5/Bestiary-Nav/main/pluginmaster.json
```

If switching from the development build, disable that copy and remove its Dev Plugin Location before installing this release. Keep the existing plugin configuration.

Automatic travel requires **Lifestream** and **vnavmesh**, installed separately. Normal map and marker features do not require those plugins. This release targets Dalamud API 15; native Bestiary features were verified against game `2026.09.01.0000.0000` and Dalamud `15.0.3.3`.

Release build: zero warnings/errors. Validation: 457 data/navigation/travel checks plus 25 native row/placement checks. Live testing confirmed markers, capture updates, flagging, the travel IPC connection and teleport-to-walking handoff. Not every physical spawn or route has been surveyed.
