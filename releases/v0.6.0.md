# Bestiary Nav 0.6.0

- Outdoor selections now show adjustable, approximate spawn-area circles on the game map.
- Added a collection window with area/duty progress, search, favorites, and Where next? suggestions.
- Added separate model/enemy-list controls, label size and colors, and clearer duty acquisition labels.
- Added an optional Beastmaster-only label filter that follows the equipped job; off by default.
- Added compact travel progress and Stop beside Auto Navigate, plus a collection book button.
- Added a saved Location pop-up toggle beside Auto Navigate. Turning it off suppresses Bestiary navigation, disables Auto Navigate, and stops the current trip. Enabling Auto Navigate also enables Location pop-up. Preserves the earlier Map Tracking toggle's saved value.
- Dungeon entries now clear existing Duty Finder selections and check the target duty, without joining the queue. Locked duties open details while preserving selections.
- While already queued, dungeon entries only highlight the duty and preserve the active queue and checked selections.
- Added Copy diagnostics and compact settings tabs.
- Includes the locally confirmed dungeon-label visibility fix.

Validation: 649 automated checks, plus native callback/signature and duty-data inspection against the supported game version. The dungeon-label fix was confirmed in-game. Map-circle rendering and the new duty-selection/UI behavior still await explicit in-game confirmation.
